# UX·UI 개선 계획 — 통일감과 밀도

> 상태: **0 · 1 · 2 · 3-①단계 완료** — 다음은 3-②(라이브러리)
> 목표: 화면마다 제각각인 크기·글자·모서리를 하나의 체계로 맞추고(통일감), 전체적으로 한 단계 촘촘하게(밀도) 만든다.

## 원칙

- **엔진(`src/engine`)·동기화(`src/sync`)는 건드리지 않는다.** UI 레이어(`src/ui`, `src/styles`)만 바꾼다.
- **보이는 것만 바꾸는 PR과 동작을 바꾸는 PR을 나눈다.**
- **PR마다 전후 스크린샷** — `npm run shots -- before` / `npm run shots -- after`(`tools/shots.ts`, 결과는 `shots/`, 저장소에 올리지 않음). `npm test`·관련 e2e 통과.
- 값은 토큰(`styles/01-base.css`)으로만 고른다. 새 규칙에 `13px`·`#xxxxxx`를 직접 쓰지 않는다.
- 밀도를 높여도 손가락 대상은 **보이는 크기 32px 이상**, 펜·손가락이 자주 누르는 곳(편집 도구창·전환 버튼)은 **40px 이상**을 지킨다.

## 0단계 감사 결과 (2026-10, iPad 1180×820 기준)

### 값 분포 — 토큰이 있어도 절반 가까이 직접 쓴 값

| 항목 | 현황 |
|---|---|
| 글자 크기 | 토큰 163곳 · 직접 쓴 값 약 150곳. **가장 많이 쓰는 13px(57곳)이 토큰 눈금에 없다.** 9 · 9.5 · 10 · 10.5 · 11.5 · 12.5 · 13.5 · 14.5 · 15 · 17 · 19 · 22 · 23px 등 반 픽셀 값이 흩어져 있다 |
| 모서리 | 토큰 113곳 · 직접 쓴 값 약 100곳. 2·3·4·5·6·7·9·10·11·12·13·16px, 알약은 `99px`·`999px` 두 가지 |
| 굵기 | 600 · 700 위주에 650 · 800이 섞임 |
| 직접 쓴 색 | hex 155곳(01-base 토큰 정의 제외), 작업보드 57곳. 상태색(`#059669`·`#dc2626`·`#d97706`)이 토큰(`--success` 등)과 따로 논다 |
| 인라인 스타일 | TSX `style={{…}}` 55곳 |

### 같은 종류인데 크기가 다른 컨트롤 (DOM 측정)

| 컨트롤 | 측정값 |
|---|---|
| 세그먼트 | 설정 › 테마 **38px / 버튼 32px · 글자 12.5px**, 설정 › 모션 **42px / 36px · 14px**, 새로 만들기 › 페이지 크기는 폭 전체로 늘어남 |
| 라이브러리 상단 바 | 아이콘 버튼 40 · 검색 38 · 정렬 select 38 · 바 높이 61px (편집 화면 문서 바는 `--toolbar-h` 52px) |
| 목록 행 | 왼쪽 메뉴 40px, ⋯ 메뉴 항목 36px, 설정 행은 설명 유무에 따라 들쭉날쭉 |
| 시트 제목 | 설정·새로 만들기 18px, 앱/파일 스토어 17px, 머지 16px, 올리기 미리보기 17px |
| 뒤로 가기 | 편집 화면은 `‹` 아이콘만, 작업보드는 파란 글자 `‹ 노트` |

### 화면별 문제

- **공통 크롬이 두껍다** — 편집 화면은 탭 바 38px + 문서 바 약 52px로 위쪽 90px를 쓴다. 라이브러리 상단 바도 61px.
- **라이브러리** — 왼쪽 메뉴 행이 40px로 성기고, 카테고리 묶음(▸ 디지털 시스템)과 일반 카테고리(● 개인)의 들여쓰기·글자 굵기가 달라 두 목록처럼 보인다. 카드 아래 캡션(제목 14 · 카테고리 12)과 `⋯`의 세로 정렬이 어긋난다.
- **설정** — 세그먼트 두 개가 높이·글자가 다르다. 슬라이더 행과 설명 있는 행의 높이가 달라 리듬이 깨진다.
- **새로 만들기** — 속지 미리보기가 아래가 잘려 보인다 — 실제로는 시트 안 스크롤 영역(`.sheet-section`) 끝에 걸린 것인데 스크롤 표시가 없어 잘린 것처럼 보인다(2단계 시트에서). 세그먼트가 폭 전체로 늘어 옵션이 왼쪽에 몰린다. 페이지 수 스테퍼가 44px로 다른 컨트롤보다 크다.
- **편집 화면** — 다크 모드에서 떠 있는 도구창이 밝은 반투명(`rgba(255,255,255,.84)` 직접 지정) 그대로라 바로 아래 ⋯ 메뉴(어두움)와 어긋난다. 굵기 선택 칩이 다크에서 거의 안 보인다.
- **작업보드** — 상단 바의 뒤로 가기·제목 스타일이 편집 화면과 다르다.
- **설정 창은 Esc로 닫히지 않는다**(시트·대화상자는 닫힘).

## 1단계 토큰 눈금

### 글자 (`--fs-*`)

눈금 사이 값은 **아래 칸으로** 내린다(밀도를 높이는 쪽). 휴대폰 카드 캡션처럼 일부러 줄인 값이 다시 커지지 않게.

| 토큰 | 값 | 흡수한 값 | 쓰임 |
|---|---|---|---|
| `--fs-2xs` | 10px | 9 · 9.5 · 10 · 10.5 | 배지·꼬리표 |
| `--fs-xs` | 11px | 11 · 11.5 | 보조 캡션 |
| `--fs-sm` | 12px | 12 · 12.5 | 설명·메타 |
| `--fs-base` | 13px | 13 · 13.5 | **UI 기본 글자** (새로) |
| `--fs-md` | 14px | 14 · 14.5 · 15 | 강조 항목·입력 |
| `--fs-lg` | 16px | 16 · 17 | 시트 소제목 |
| `--fs-title` | 18px | 18 · 19 | 시트·패널 제목 (새로) |
| `--fs-xl` · `--fs-2xl` | 20 · 24px | 20 · 22 · 23 · 24 | 큰 제목 |

텍스트 문서 본문(`15-textdoc.css`의 `.tb-text`·`.tm-text`·제목 블록), 인쇄용 `pt`, `em` 값, 30px 이상의 표시용 글자는 **내용 글자**라 눈금에서 뺀다.

### 모서리 (`--r-*`)

| 토큰 | 값 | 흡수한 값 |
|---|---|---|
| `--r-2xs` | 4px | 4 · 5 |
| `--r-xs` | 6px | 6 · 7 |
| `--r-sm` | 8px | 8 · 9 |
| `--r-md` | 10px | 10 · 11 |
| `--r-lg` | 12px | 12 · 13 |
| `--r-xl` | 14px | 14 · 16 |
| `--r-2xl` | 18px | 18 |
| `--r-pill` | 999px | 99 · 999 |

1–3px(꼬리표·눈금선 같은 잔 장식)와 `50%`(원)는 그대로 둔다.

## 1b단계 크기 토큰 — 밀도 '한 단계'

| 토큰 | 값 | 이전 | 쓰는 곳 |
|---|---|---|---|
| `--h-bar` | 52px | 60px | 라이브러리 상단 바 |
| `--h-control` | 34px | 36–44px | 검색·정렬·상단 바 아이콘 버튼·`.primary-btn`·`.text-btn`·입력(`.field`·`.modal-input`)·스테퍼·가져오기 버튼·선택 모드 버튼·동기화 패널 검색·칩 |
| (세그먼트 버튼) | `--h-control` − 6px = 28px | 32 / 36px | `.seg` 전부 같은 높이·`--fs-base` 글자 — 바깥 높이가 `--h-control`과 같다 |
| `--h-control-sm` | 28px | 32px | `.text-btn.small` |
| `--h-row` | 32px | 36 / 40px | 왼쪽 메뉴 행, ⋯ 메뉴 항목 |
| `--h-tap` | 40px | — | 펜·손가락이 자주 누르는 곳의 하한 — 편집 도구창·카드 여는 판·머지 도구는 이번에 줄이지 않았다 |

설정 행 최소 높이는 44 → 40px. 더 촘촘하게 하려면 이 토큰 값만 바꾼다(‘두 단계’ 안: 30 · 24 · 28px).

## 1c단계 색

직접 쓴 색 117곳 가운데 **뜻이 있는 색**과 **테마를 따라야 하는 색**을 토큰으로 옮겼다.

| 토큰 | 쓰는 곳 | 다크 |
|---|---|---|
| `--mark-o` · `--mark-x` · `--mark-ex` | 카드 마킹 ○ ✕ ! | 같은 값 — 카드 미리보기(늘 밝음) 위 |
| `--paper-line` · `--paper-dot` · `--paper-margin` | 속지 미리보기(새로 만들기·보조 용지) | 같은 값 — 종이 |
| `--scrim` | 모달·진행 덮개 | 같은 값 |
| `--tint` · `--tint-2` | 옅은 채움·머리카락 선 (잉크 6% · 13%) | 잉크를 따라 밝은 선으로 |
| `--merge-main` · `-branch` · `-mod` · `-del` (+ `-ink`) | 머지 화면 칩·쪽 이름, 변경 목록 칩 | `-ink`는 밝게 — 어두운 바탕에서 읽힘 |
| `--code-ink` | 문서 인라인 코드 | 밝은 주황 |
| `--warn` · `--warn-ink` (기존) | 낙서 모드 배너·저장 안 됨 표시 — 따로 쓰던 `#b26a00`·`#e8a33d`·`#8a5200` 대신 | 기존 다크 값 |

**편집 도구창은 테마와 상관없이 밝다.** 흰 종이 위에 떠서 펜 색·굵기를 종이에 그릴 그대로 보여 주는 '종이 쪽' UI다. 전에는 바탕만 흰색으로 박아 두고 안쪽 칩·선·활성 표시·팝오버는 다크 값을 받아 섞였다(굵기 칩이 안 보이고, 팝오버만 어두웠다). 이제 `01-base.css`의 밝은 팔레트 블록을 `.ft-bar`·`.ft-pop`에도 그대로 씌운다.

그대로 둔 것: 작업보드 배경화면(테마마다 따로 정의되어 있음), 인쇄용 색, 그림자, 카드 미리보기 위 반투명 흰·검정(늘 밝은 종이 위), 메모 블록 글자색(파스텔 종이 위).

## 2단계 공용 그릇·메뉴

**Esc로 닫기 — 한 규칙.** `ui/sheetParts.tsx`의 `useEscClose(onClose, enabled)`를 모든 모달·시트가 쓴다.
겹치면 맨 위 하나만 닫고, 그 위에 확인창(`.dialog-host`)·⋯ 메뉴가 떠 있으면 그쪽이 먼저 닫힌다. 입력칸이 Esc를 따로 쓰면 `preventDefault`로 알린다(기기 이름 고치기 취소).
전에는 설정·동기화·보관함·앱·파일·에셋·프리셋·카테고리 지정·올리기/받기 미리보기·Inkpad에서 고르기가 Esc로 닫히지 않았다. 새로 만들기·이미지로 보내기·변경 목록은 각자 쓰던 처리를 이 훅으로 바꿨다. `tools/e2e/esc.ts`가 지킨다.

**그릇 모양 — 한 벌.**

| | 전 | 후 |
|---|---|---|
| 모서리 | `.modal` 14 · `.sheet`·`.store-sheet` 18px | 모두 `--r-xl` |
| 그림자 | `.store-sheet`만 직접 쓴 값 | 모두 `--e3` |
| 제목 | 18 · 18 · 16px | 모두 `--fs-lg` |
| 머리 | `.sheet` 닫기 버튼 44px로 약 61px, `.store-head` 40px 아이콘으로 약 69px | 높이 `--h-bar`, 닫기 버튼 `--h-control`, 스토어 아이콘 32px |
| 스크롤 | 잘린 것처럼 보임 | `.sheet-scroll`·`.sheet-section`·`.store-body`에 스크롤 그림자 — 위·아래로 더 있으면 가장자리가 옅게 어두워진다 |

**⋯ 메뉴.** 스토어 팝오버(`.store-pop`)를 공용 `.menu`와 같은 그릇(안쪽 여백 4px·그림자·테두리)과 항목(최소 `--h-row`, 글자 `--fs-md` 보통 굵기)으로.
편집 도구창 ⋯(`.ft-pop.is-menu`)은 3-①에서.

## 3-①단계 편집 화면 크롬

| | 전 | 후 |
|---|---|---|
| 탭 바 | 38px | `--h-control` 34px |
| 상단 바 높이 `--h-bar` | 52px(라이브러리)·53px(편집 문서 바)·약 53px(작업보드·앱 실행) | 모두 46px — `--toolbar-h`도 이 값을 따른다 |
| 편집 문서 바 버튼 | 44px | `--h-tap` 40px (작업보드·앱 실행 상단 바도) |
| 문서 제목 버튼·이름 입력 | 44 / 36px | `--h-control` |
| 위쪽 크롬 합계(편집 화면) | 약 91px | 약 80px |

- 문서 바 묶음 사이 세로선을 없앴다 — 제목 바로 옆에 떠 보였다.
- 도구창 ⋯ 메뉴(`.ft-pop.is-menu`) 그릇을 공용 `.menu`와 같게(안쪽 여백 4px·`--r-lg`).
- 작업보드 '‹ 노트'를 파란 링크 대신 먹색 — 다른 상단 바와 같은 결.
