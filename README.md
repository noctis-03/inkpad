# Inkpad (가칭)

iPad + Apple Pencil용 개인 필기 웹앱 (PWA). 단계별로 구현 중.

## 현재 단계: Phase 1 로컬 MVP + Phase 2 Google Drive 동기화 (완료)

### 완료된 기능
**필기 엔진 (Phase 0 + 1)**
- 펜/터치 분리, 필압, `getCoalescedEvents`, `getPredictedEvents`(펜 끝 예측), 팜 리젝션
- 두 손가락 팬/핀치 줌(10%~2000%), 한 손가락 스크롤 관성, 두 손가락 탭 = Undo, 세 손가락 탭 = Redo
- 확정 레이어 / 입력 레이어 / 페이지(속지·PDF) 레이어, R-tree로 화면에 보이는 획만 그리기, LOD, 캔버스 픽셀 상한
- 그릴 것이 있을 때만 프레임을 돌린다 — 노트를 열어 두고 가만히 있으면 화면을 다시 그리지 않는다(배터리). 성능 표시(HUD)를 켜면 측정을 위해 계속 돈다
- 키보드 단축키: ⌘Z / ⇧⌘Z, P/H/E/L(도구), Delete(선택 삭제), Esc

**필압 지원 여부에 따른 옵션 (신규)**
| 방식 | 설명 |
|---|---|
| 자동 감지 (기본) | 한 획 안에서 필압이 변하면 "지원", 고정값(0.5/1.0 등)만 오는 획이 연속 2번이면 "미지원"으로 판정해 기기에 저장. 미지원이면 대체 방식으로 자동 전환하고 알림 |
| 필압 | 항상 필압 사용 (Apple Pencil) |
| 속도 | 필압 없는 펜·손가락용. 빠르게 그리면 가늘게 (perfect-freehand simulatePressure) |
| 일정한 굵기 | 굵기 변화 없음 |
- "필압이 없을 때" 대체 방식(속도/일정): 자동 감지 결과가 '없음'일 때, 그리고 손가락·정전식 터치펜·마우스 입력에 적용
- 굵기 변화 폭, 필압 곡선(감마), 최소 필압 조절
- 설정 안의 **필압 테스트 패드**: 그어 보면 pointerType, 필압 범위, 판정 결과를 보여주고 감지 결과를 갱신
- 획마다 외곽선 옵션을 저장하므로 설정을 바꿔도 이미 그린 획 모양은 그대로
- 정전식(고무팁) 터치펜은 브라우저에서 손가락과 구분되지 않으므로 "손가락·터치펜으로 그리기"를 켜서 사용

**시작 화면**: 앱을 처음 열 때 노트 카드 → 줄 → 파란 획(앱 아이콘)이 그려지고 'Inkpad'가 떠오른다(약 1.2초, `index.html` — 앱 코드를 받기 전부터 보인다). 앱이 늦게 준비되면 획이 숨쉬며 기다린다. 다크 모드·동작 줄이기 대응

**노트 여는 방법** (라이브러리 격자에서 카드를 누르면 고른다) — 카드를 누르면 미리보기 아래쪽만 흐려지고(위쪽은 또렷해 어느 노트인지 보인다) 왼쪽 위에 쪽수·날짜, 카드 아래쪽(손가락이 닿는 자리)에 큰 **편집**(44px)과 작은 **보기** · **낙서**(40px, 낙서는 점선 — 남지 않는다)가 뜬다. 휴대폰 카드는 모두 40px, 보기·낙서는 아이콘 위·이름 아래. 카드 종이는 테마와 상관없이 밝으므로 판도 테마와 상관없이 먹·종이 색(다크에서도 또렷하다). 버튼 밖을 누르면 닫힌다. 앱·파일 카드도 같은 판(▶ 실행 · 열기 하나)
- **편집**(편집모드): 평소대로 쓰고 저장한다
- **보기**(뷰어보드): 읽기 전용
- **낙서**(낙서모드): 쓸 수 있지만 **아무것도 저장하지 않는다** — 기록·올리기 대기·편집 잠금·보던 위치·카드 미리보기 모두 건드리지 않고, 나가면 쓴 것은 사라진다. 툴바에 '저장 안 됨', 아래에 안내와 **모두 지우기**(처음 연 상태로). 이름 바꾸기·노트 동기화 칩·버전 기록은 내지 않는다
- 열어 둔 노트에서도 문서 바의 **편집 | 보기 | 낙서** 전환(휴대폰·듀얼은 ⋯ 메뉴)으로 같은 노트를 다른 방식으로 다시 연다 — 쓴 것은 기록한 뒤 바꾸고, 낙서에서 나가면 쓴 것은 사라진다

**선택 모드 · 마킹** — 라이브러리에서 노트·앱·파일 카드를 **꾹 누르면** 손가락 둘레에 **원형 메뉴**(위 ○ · 오른쪽 ✕ · 아래 ! · 왼쪽 지우기)가 뜬다. 떼지 않고 그 쪽으로 밀어 떼면 그 카드에 바로 마킹(이미 같은 마킹이면 뗀다 — 메뉴에 테두리로 표시), 멀리 나가 떼면 취소, 메뉴가 떠 있는 동안은 화면이 스크롤되지 않는다. 선택 모드에서 선택된 카드를 밀면 선택된 카드 전부에 붙는다. **가운데서 그냥 떼면** 선택 모드(누른 카드가 선택된다). 상단 바가 **[완료 · N개 선택됨 · 전체 선택 · ○ ✕ ! · 마킹 지우기]**로 바뀌고, 탭은 열지 않고 선택/해제만 한다. 마킹은 ○·✕·! 중 **하나만** 붙고(다른 걸 누르면 바뀐다, 모두 같은 마킹일 때 한 번 더 누르면 뗀다) 카드 미리보기 한가운데에 반듯한 기호로 크게 보인다. 마킹하는 순간 도장 찍히듯 나타나고, 뒤의 미리보기는 옅게 블러한 뒤 마킹 색으로 살짝 물들이고 옅은 빗금을 그어 내용의 형체는 보이게 둔다(카드를 눌러 여는 창이 뜨면 이 막은 사라져 블러가 겹치지 않는다). 카드 테두리는 마킹 색 얇은 선. 확인했는지·다시 볼지 표시하는 용도라 **이 기기에만 저장**하고 동기화하지 않는다(노트 파일·수정 시각도 그대로). 영구 삭제한 항목의 마킹은 저절로 정리된다. 완료·Esc·다른 섹션으로 가면 끝난다

**카테고리 묶음** — 카테고리 이름을 `[과제] 디지털 시스템`처럼 `[태그] 이름`으로 지으면, 왼쪽 메뉴의 카테고리 목록에서 **뒤쪽 이름**(디지털 시스템)이 묶음 머리글이 되고 그 아래에 **태그**(과제·시험…)가 항목으로 들어간다. 묶음이 이름 순으로 먼저 → 태그 없는 카테고리 → 미분류. 머리글 **이름을 누르면 묶음 화면** — 그 묶음 노트 전부를 태그별 소제목(색 점·이름·개수, 누르면 그 태그만)으로 나눠 보여 주고 묶음을 펼친다(한 번 더 눌러 최근 열람으로 보면 나누지 않고 최근 순). 머리글 왼쪽 **화살표는 접고 펴기만** 한다 — 접히면 안쪽 항목 색 점(최대 4개)과 묶음 전체 개수, 펼치면 안쪽 항목을 들여 쓰고 왼쪽 세로 안내선으로 묶는다. **고른 것만 펼친다** — 펼친 묶음은 한 번에 하나: 묶음(또는 그 안의 카테고리)을 고르면 그 묶음만 펼치고 다른 묶음은 접히며, 묶음 밖을 고르면 모두 접힌다. 화살표로 펼쳐도 하나만. 편집 화면에 다녀와도 그대로지만 새로고침·앱을 다시 켜면 모두 접힌 채로 시작한다(보던 카테고리가 묶음 안이어도). 보고 있는 카테고리의 묶음이 접혀 있으면 선택 표시는 머리글에. 따로 만들 것 없이 이름만 보고 묶으며, 카테고리 자체(이름·동기화)는 그대로다. 카테고리 색은 **태그가 있으면 태그만 보고** 정한다(`[과제] 디지털 시스템`과 `[과제] 회로 실습`은 같은 색). 색은 이름을 해시해 하나씩 고르지 않고 **이 기기의 카테고리 전체를 보고 배정**한다 — 겹치는 카테고리가 없다: 가나다순(코드 순)으로 원래 색(이름 해시가 고르는 팔레트 칸)이 비어 있으면 그 색(겹치지 않던 카테고리는 색 그대로), 뺏겼으면 팔레트 12색의 다음 빈 색, 12색을 다 쓰면 이미 쓴 색·미분류 회색과 사람 눈 기준(OKLab)으로 가장 먼 색을 새로 만든다(밝은·어두운 바탕 모두에서 보이는 밝기와 또렷한 채도 안에서). 같은 카테고리 목록이면 어느 기기에서나 같은 색. 카테고리가 늘면 겹쳐서 밀려났던 것만 색이 바뀔 수 있다. 점이 작아 20개쯤부터는 다르지만 비슷해 보이는 색이 생긴다 `[과제]`처럼 태그 뒤에 이름이 없으면 묶지 않는다

**도구**
- 편집 도구창(떠 있는 바, 위·아래·옆으로 끌어 옮긴다): **[도구 4] | [색 5 · 굵기 3(가늘게·보통·굵게) · 지금 펜 미리보기] | [되돌리기·다시] ⋯**. 회색 상자 없이 하나의 바를 얇은 선으로 나눈다. 미리보기(또는 선택한 도구를 한 번 더)를 누르면 색 전체·굵기 6단계. 블록 추가·사진 넣기·전체 보기·도구 메뉴 접기·상단 중앙으로는 ⋯ 메뉴. 폭이 좁으면 색·굵기를 미리보기 하나로 줄이고 되돌리기도 ⋯로
- 펜↔지우개 전환 버튼: 필기 영역 왼쪽 아래(끌어 옮긴다, 영역 크기가 바뀌면 안으로 다시 맞춘다)
- **미니맵**(`ui/editor/Minimap.tsx`): 확대해 좌우가 화면 밖일 때만 필기 영역 왼쪽 위에 가는 막대 하나(폭 160px)로 나타난다 — 회색 막대는 지금 보는 높이의 가로 전체 폭(페이지·보조 용지·페이지 밖으로 나간 필기까지), 파란 구간은 지금 보이는 부분, 검은 눈금은 필기가 있는 가로 자리(화면 밖은 진하게). 파란 구간 바깥에 눈금이 있으면 화면 밖 왼쪽·오른쪽에 필기가 있다는 뜻이다(필기 모양은 그리지 않는다). 폭 맞춤(100%)처럼 좌우가 다 보이면 숨는다. 무한 캔버스에서도 나온다
  - 누르거나 그 위에 써도 아무 반응이 없다(입력을 받지 않는다) — 그 자리에 평소처럼 필기된다. 펜이 미니맵 아래로 오면(대거나 띄워 가까이) 흐려져 쓰는 글씨를 가리지 않고, 펜을 떼면 다시 또렷해진다
  - 도구창과 겹치면 비켜 선다(가로 도구창이면 그 아래, 세로 도구창이면 그 오른쪽). 화면이 움직이거나 필기가 바뀔 때만 작은 캔버스를 다시 그린다. 설정 > 화면 > 미니맵으로 끈다
- **사진 넣기**(`ui/editor/insertPhoto.ts`, 엔진 `insertImage`, 비트맵 `engine/images.ts`): ⋯ 메뉴 **사진 넣기**(아이패드는 사진 보관함·사진 찍기·파일, 한 번에 10장까지) 또는 붙여넣기(⌘V). 긴 변 2048px까지 줄여 원본(에셋, PDF와 같은 내용 주소 저장·동기화)으로 저장하고 지금 보는 화면 가운데에 화면의 60%(문서형은 페이지의 80%) 안으로 놓는다 — 원래 크기(1px = 1pt)보다 키우지 않는다. JPEG 등은 다시 그려 저장해 EXIF 회전을 픽셀에 굽고 위치 정보 같은 메타데이터는 떨어진다(작은 PNG는 그대로)
  - 사진은 노트 청크의 이미지 요소(`ImageElement`)로 획과 함께 저장된다. 늘 **획 아래**에 그려 사진 위에 필기한다. 보조 용지 위 사진은 용지 안으로 자른다
  - 넣으면 올가미로 바뀌고 그 사진이 골라져 있다. 올가미로 사진을 **누르면** 그 사진(맨 위)만 고르고, 올가미로 **감싸면**(사진 가운데가 안에 들면) 획과 함께 고른다 — 끌어 옮기기(문서형은 가운데가 들어간 페이지로 소속이 바뀐다)·모서리로 정비율 크기 조절·복제·삭제가 획과 같고 모두 되돌리기. 지우개로는 지우지 않는다. 사진만 고르면 색 바꾸기는 숨는다
  - 이미지로 보내기·페이지 미리보기·카드 미리보기·PDF 내보내기(pdf-lib에 PNG·JPEG로 넣는다)·.inkpad 백업에 함께 담긴다. 원본이 이 기기에 없으면 PDF처럼 열 때 받아 온다(받기 전·실패하면 회색 자리). 낙서 모드에는 메뉴가 없다(원본을 저장하지 않으려고). 머지 화면은 아직 사진을 그리지 않는다
- 펜(색 8 + 직접 선택, 굵기 6단계), 형광펜(반투명, 필기 아래 레이어), 프리셋 5개(탭 = 적용, 길게 누르기 = 현재 펜으로 저장)
- 지우개: 획 단위 (닿은 획을 통째로 지운다 — 획을 잘라 조각을 만들지 않아 기기 간 머지가 단순하다)
- 올가미: 선택 → 끌어서 이동, 삭제, 복제, 색 바꾸기 (문서형에서는 다른 페이지로 옮기면 해당 페이지 소속으로 바뀜)
  - **크기 조절**: 획·사진을 고르면 고른 영역 네 모서리에 동그란 핸들이 뜬다. 핸들을 끌면 반대쪽 모서리를 고정하고 **정비율**로 키우거나 줄인다(굵기도 같은 비율, 올가미 영역도 함께). 끈 점을 대각선에 비춰 비율을 정하고, 화면에서 대각선 24px 아래로는 줄지 않는다. 되돌리기 한 번에 원래대로
  - **자유 / 사각 올가미**: 올가미를 고르면 도구창의 색·굵기 자리에 **자유 · 사각**이 바로 보인다(설정에 기억, 사각이면 도구 아이콘도 네모, 세로 배치에서는 아이콘만). 고른 영역은 올가미 모양 그대로 움직이는 점선으로 보이고, 획 없이 감싸도 **영역**으로 남아 이미지로 보내기만 할 수 있다(인쇄된 PDF 문제만 보낼 때)
- Undo/Redo 200단계 (페이지 삭제·복제·순서 변경·속지 변경 포함, 페이지 삭제 되돌리기 시 필기도 함께 복원)

**문서형 / 무한 캔버스**
- 문서형: A4 / Letter / A5 / 사용자 지정(mm), 세로·가로, 속지 5종(무지·줄·모눈·점·코넬), 세로 연속 스크롤
- 페이지 추가·삭제·복제·순서 변경(썸네일 길게 눌러 끌기 또는 메뉴), 썸네일 사이드바, 현재 페이지 표시
- 무한 캔버스: 청크(4096) 단위 저장, 점/격자/줄/무지 배경, 전체 보기, 원점 이동

**PDF**
- 가져오기: 새 문서로 / 기존 문서에 페이지 삽입, SHA-256 중복 제거, 암호 PDF(비밀번호 입력, 저장 안 함), 손상 PDF 안내, 페이지별 크기·회전(/Rotate) 반영, 200MB 상한
- **페이지 크기 맞추기**: 스캔·슬라이드 PDF는 페이지 크기가 제각각이라(스캔은 A4의 4배가 넘기도 한다) 같은 펜이 페이지마다 다른 굵기로 보인다. 가져올 때 페이지 폭이 A4의 0.8배 미만이거나 1.25배를 넘으면 **원본 크기**(기본) · **A4 폭에 맞춤**을 묻는다(지난 선택을 이 기기에 기억해 그 버튼을 강조, A4쯤이면 묻지 않는다). 가져온 뒤에도 페이지 메뉴(썸네일 ⋯·페이지 칩)와 페이지 패널의 **A4 폭에 맞추기** · **원래 크기로**로 바꾼다(패널은 현재/모든 페이지, 속지 페이지도 된다). 세로 페이지는 A4 폭(595pt), 가로 페이지는 A4 가로 폭(842pt)에 맞춘다
  - 페이지 크기와 **내용 배율**(`Page.scale`)만 바꾸고 획 좌표는 건드리지 않는다 — 필기·속지 무늬·PDF는 페이지와 함께 늘고 줄며, 몇 번을 맞추고 되돌려도 획은 원래 그대로(오차 0)이고 다른 기기에서 같은 페이지에 쓴 획과도 부딪히지 않는다. 맞춘 페이지에 새로 쓰는 획은 고른 펜 굵기 그대로 보이게 원래 크기 기준으로 저장한다
  - 블록·떠 있는 보조 용지는 같은 비율로 자리를 옮긴다(블록 크기는 그대로). 아래 페이지들은 화면에서 자리만 밀리고 필기는 각자 페이지를 따라간다. 보던 자리(화면 가운데의 페이지 위 지점, 폭 맞춤 대비 배율)는 그대로, 되돌리기 한 번에 원래대로
  - PDF·이미지로 내보내기·카드 미리보기·병합 화면도 맞춘 크기로 그린다
- 렌더링: pdf.js(legacy 빌드, Web Worker), 줌 단계별 해상도 비트맵 + LRU(총 픽셀 상한), 화면 근처 페이지만 렌더링, 다음 페이지 미리 렌더링
- **이미지로 보내기**(`ui/editor/SendImageSheet.tsx`, 엔진 `exportImage`): 노트 ⋯ 메뉴 **이 페이지를 이미지로 보내기**(무한 캔버스는 지금 화면), 페이지 사이드바 메뉴, 올가미 도구 모음의 공유 버튼으로 그 페이지·**올가미 영역을 그 모양 그대로**(고른 획 기준이 아니다 — 걸친 획은 경계에서 잘린다) PNG로 다시 그린다 — 화면 줌과 관계없이 긴 변 2000px(1pt에 4px까지), 흰 바탕. **PDF·속지 포함**을 고를 수 있다(올가미는 기본 글씨만, 페이지는 기본 포함 — 각각 이 기기에 기억). **요청 문구**는 이미지 위쪽 띠에 글자로 넣는다(기본: 글씨만이면 "이 손글씨를 그대로 텍스트로 다시 적어줘.", PDF 포함이면 "사진 속 내용을 쉽게 풀이해줘." — 고칠 수 있고 끌 수 있다. 공유·붙여넣기로 문구를 따로 넘기면 받는 앱마다 다르게 다뤄서 이미지 안에 넣는다). 블록(메모·할 일)은 담지 않는다. 미리보기를 보고 **복사**(클립보드) 또는 **공유**(iPad 공유 시트, 공유할 수 없으면 저장) — 화면 분할로 옆에 띄운 Claude 같은 AI 앱에 붙여넣어 묻는 용도. 이 기기 안에서만 만들고 어디에도 올리지 않는다(네트워크 0)
- 내보내기: pdf-lib(Web Worker)로 **원본 PDF 페이지 위에 필기를 벡터로 합침**, 형광펜 투명도, 속지 무늬 벡터, 전체/현재/범위 지정, 암호 PDF는 원본을 이미지로 대체(필기는 벡터 유지)
- 무한 캔버스 → 필기 영역 전체를 PDF 1페이지로

**문서 관리 / 저장**
- 문서 목록(그리드/리스트, 썸네일, 수정일·만든 날·제목 정렬, 제목 검색), 중첩 폴더, 폴더로 이동, 복제, 이름 바꾸기
- 휴지통(30일 뒤 자동 영구 삭제, 복원, 비우기), 휴지통 이동 실행 취소
- 격자 카드 미리보기는 저장된 미리보기 이미지를 디더 없이 카드 미색 바탕 위에 곱하기(multiply)로 얹는다 — 흰 종이 자리만 미색이 되고 필기·그림 색은 그대로. 미리보기 없는 카드도 같은 미색 바탕(`--thumb-cream`, 라이트 `#fbf9f4` · 다크는 조금 어둡게 `#dfdbd1`). 카드 뒤 바탕(`--lib-bg`)은 앱 바탕보다 라이트에선 조금 어둡게(`#eeedea`), 다크에선 밝게(`#2a2825`)
- **탭 (크롬처럼)**(`ui/TabBar.tsx`, store `tabs`): 노트·앱·파일을 열면 위에 탭이 생긴다 — 새 탭은 지금 탭 바로 뒤에, 맨 앞 **홈 탭**은 마지막으로 본 라이브러리(또는 작업보드). 탭을 눌러 오가고 ×(또는 가운데 버튼)로 닫는다 — 보던 탭을 닫으면 오른쪽 이웃(없으면 왼쪽, 탭이 없으면 홈)으로. 오른쪽 클릭 메뉴: 옆 칸에 열기 · 탭 닫기 · 다른 탭 모두 닫기. 열린 것이 없어도 바(홈 탭)는 늘 있다. 탭 목록·옆 칸·칸 비율은 **이 기기에만** 기억해(`inkpad.tabs.v1`, 동기화하지 않음) 다시 켜도 그대로고, 휴지통으로 보내거나 지운 항목의 탭은 저절로 닫힌다. **앱 탭은 숨겨 둔 채 켜 둔다** — 다른 탭에 다녀와도 앱 안의 상태가 남는다(최근 본 앱 5개까지, 넘으면 가장 오래 안 본 앱부터 끄고, 다시 켜면 볼 때 켠다). 노트·파일은 볼 때만 그린다(노트 편집 화면은 무겁고, 보던 위치는 노트가 기억한다)
- **상태 칸**(`ui/dock/`, `shared/activity.ts`): 탭 바 오른쪽 끝의 한 줄짜리 칸. 올리기·받기(노트 하나·전체), 원본·앱·파일·프리셋 받기와 올리기, PDF·.inkpad 가져오기, 내보내기·백업 같은 일은 **화면을 막지 않고** 여기에 진행률과 함께 보인다(예전의 화면 전체를 덮던 진행 창은 없앴다). 좌우로 넘겨(손가락·트랙패드 밀기, 마우스 끌기·휠, ←/→) **전송 · 동기화 · 저장 공간** 쪽을 보고, 누르면 칸이 그 자리에서 커져 자세히 보는 창이 된다(Esc·창 밖 누르기로 닫으면 다시 칸으로 줄어든다). 실패한 일을 아직 열어 보지 않았으면 칸에 빨간 점. 기록은 메모리에만(최근 30건). 쪽은 `ui/dock/pages.tsx`의 `DOCK_PAGES`에 더한다
- **노트 열기·닫기 모션**(`app/App.tsx` Panes): 홈(라이브러리·작업보드)에서 노트를 열면 라이브러리 위로 편집 화면이 서서히 나타나고, 돌아가면 편집 화면이 라이브러리 위에서 서서히 사라진다(크로스페이드, 둘 다 0.45초) — 그동안 바뀌기 전 화면을 잠깐 남겨 겹쳐 바꾼다. 탭 전환 등 그 밖의 경우는 조용한 페이드업, 모션 끄기에서는 바로 바뀐다
- **듀얼 (옆 칸)**(`app/App.tsx` Panes): 앱·파일 화면 머리의 **옆 칸에 띄우기**(또는 탭 메뉴)로 그 앱·파일을 옆 칸에 두고, 가운데에서 노트(또는 라이브러리·다른 탭)를 본다 — 가운데에는 그 전에 보던 화면이 온다. 가운데 탭을 바꿔도 옆 칸은 그대로. 사이 막대를 끌어(화살표 키로도, 두 번 누르면 처음 비율) 폭을 바꾸고, 노트 화면은 칸 폭에 맞춘다. 옆 칸 머리의 **⇄ 좌우 바꾸기**(탭 메뉴에도)는 옆 칸을 왼쪽↔오른쪽으로 옮긴다 — 각 칸의 폭은 그대로, 앱은 다시 로드되지 않고, 고른 쪽은 이 기기에 기억한다. ×는 칸만 닫고(탭은 남는다) ⤢는 가운데로 크게. 옆 칸에는 앱·파일만 — 노트 편집 화면은 도구·선택·보기 상태를 앱 전체에 하나만 두기 때문. 폭이 760px보다 좁으면 칸을 숨기고(기억은 한다) 띄우기 버튼도 내지 않는다. 모든 칸은 같은 부모 아래에서 CSS grid 자리만 바꾸므로 앱을 옆 칸으로 옮기거나 되돌려도 다시 로드되지 않는다
- **끌어 놓기로 추가**: 라이브러리 화면에 파일을 끌어다 놓으면(iPad는 Split View·Slide Over의 파일 앱에서) **파일 추가**와 같은 길로 나눠 넣는다 — PDF는 노트(지금 보는 폴더로), HTML은 앱, `.inkpad`는 가져오기, 나머지는 기타 파일(큰 파일 확인도 같다). `.zip`은 안의 `manifest.json`만 풀어 보고 Inkpad 파일일 때만 가져오고, 일반 zip은 기타 파일로 넣는다. 파일을 끌고 들어오면 화면에 **여기에 놓아 추가** 표시가 뜨고, 나가거나 놓으면 사라진다(파일이 아닌 끌기에는 뜨지 않는다)
- **앱·파일 카드**: 노트 카드와 같은 구조 — 미리보기 아래 제목 · 카테고리 · ⋯, 격자에서 카드를 누르면 오버레이(종류 · 날짜 + **▶ 실행** · **열기**), 목록에서는 바로 연다. **파일**은 원본이 이 기기에 있을 때 이미지 · PDF 첫 쪽 · 텍스트 앞부분을 미리보기로 그린다 — 노트 미리보기처럼 **이 기기에만** 저장하고(`itemThumbs`, 동기화하지 않음, 캐시 삭제로 지워진다), 미리보기를 만들려고 원본을 받지는 않는다(한 번 열어 원본이 생기면 그때). 시트 등 그릴 수 없는 형식과 원본이 없는 파일은 아이콘. **HTML 앱**은 미리보기를 만들지 않고 늘 아이콘(예전에 저장한 앱 미리보기는 라이브러리가 지운다). 동기화 꼬리표·빗금은 붙이지 않는다(추가·수정하자마자 올리므로) — 올라가는 동안만 제목 뒤에 로딩 고리
- **HTML 앱의 파일 주고받기**(`ui/app/bridge.ts`, sandbox iframe이라 앱이 직접 못 하는 것을 Inkpad가 대신한다): 앱이 파일을 **불러오면**(`<input type="file">`) "기기에서 고르기 / Inkpad에서 고르기", **내보내면**(`<a download>`의 blob:·data: 링크 — 화면에 없는 링크의 `click()`·`dispatchEvent`도, `showSaveFilePicker`, `window.inkpad.saveFile(data, 이름, 형식)`) 브라우저가 바로 받지 않고 **파일 저장** 창: **기기에 저장**(iPad는 공유 시트 → "파일에 저장") · **Inkpad에 저장** — 라이브러리의 **파일 추가**·끌어 놓기와 같이 형식별로 나눠 넣는다(`io/fileRoute.ts`): 나머지 파일은 앱과 같은 카테고리의 **기타 파일**로 추가하고 그 파일만 바로 클라우드에 올리고(오프라인이면 대기), HTML은 **앱으로 저장**, `.inkpad`(Inkpad zip 포함)는 **노트로 가져오기**, PDF는 **노트로 저장**(기본 — 앱과 같은 카테고리, 클라우드에는 동기화의 올리기로)과 **기타 파일로**(보관용, 바로 업로드) 중에 고른다. 기타 파일의 큰 파일 확인은 이 창에 합쳐 두 번 묻지 않는다 — 확인할 크기면 **Inkpad 이 기기에만**(올리지 않음)도 보인다(PDF를 기타 파일로 고를 때는 그때 묻는다). 여러 파일을 한꺼번에 내보내면 차례로 묻고, 앱은 저장 여부를 받는다(`saveFile`은 true/false, `showSaveFilePicker`는 취소하면 `close()`가 AbortError)
- **목록 보기**: 노트·앱·파일 모두 제목 아래 한 줄 `카테고리 · 쪽수(종류) · 날짜`, 오른쪽에 꼬리표(노트) · ▶(앱·파일) · ⋯. 앱·파일은 썸네일 자리에 줄 그은 종이 배지 + 확장자(APP · PDF …)
- 카드 동기화 꼬리표는 각진 흑백 꼬리표(`.sync-tag`): `↑ 올리기` · `· 이 기기만` · `↓ 새 버전`(먹색 반전) · `! 갈라짐`(빨강). 동기화됨은 붙이지 않는다. 격자는 미리보기 왼쪽 아래, 목록은 캡션 오른쪽. 꼬리표가 붙은 격자 노트 카드는 종이 바탕에 먹색 빗금(45°, 굵기 12px · 간격 18px, `--sync-hatch*`) — 미리보기 위에 곱하기로 얹어 흰 종이 자리에만 보이고 필기는 가리지 않으며, 마킹 빗금(-45°, 마킹 색)과 방향·색이 다르다. 편집 화면의 노트 동기화 칩은 그대로
- 카드 미리보기 일괄 새로 고침: 상단바 ☁ 메뉴의 **카드 미리보기 새로 고침**으로 만들 수 있는 미리보기를 한 번에 다시 만든다 — 원본이 없어 만들 수 없는 PDF 노트는 건너뛴다(원본을 받으면 대상에 들어온다)
- 빠진 노트 원본 받기: 상단바 ☁ 메뉴의 **빠진 노트 원본 받기**(카드 미리보기 새로 고침 아래) — '받기'는 메타데이터만 받으므로 다른 기기에서 온 PDF·이미지 노트는 열 때까지 원본이 없다. 이 메뉴는 노트(이 기기 휴지통 제외)가 쓰는데 이 기기에 없는 원본만 골라 한 번에 받는다(어느 노트도 쓰지 않는 원본은 받지 않는다 — 그건 에셋 원본 시트에서). 큰 전송 확인은 다른 받기와 같은 기준, 받는 동안 진행 표시(n/전체), 끝나면 받은 개수·실패 개수(로그인 만료는 따로)를 알리고 그 노트들의 카드 미리보기를 원본으로 다시 만든다. 받을 것이 없으면 알리기만 한다
- 상단바는 폭에 따라 줄어든다: 980px 이하(iPad 세로)는 격자/목록·정렬·작업보드를 ⋯ 메뉴로, 700px 이하(휴대폰)는 검색을 돋보기 버튼으로 접고(누르면 상단바 전체가 검색창, 취소로 닫기) 설정도 ⋯ 메뉴로, 새로 만들기는 ＋만 남긴다
- IndexedDB(Dexie): 획이 끝나면 500ms 디바운스로 바뀐 청크만 gzip 압축 저장, 백그라운드 전환·종료 시 즉시 저장, 저장 실패 시 재시도·용량 부족 안내
- 모든 쓰기를 같은 트랜잭션에서 outbox에 기록 (Phase 2 동기화 준비), 같은 엔티티는 합침
- schemaVersion + 마이그레이션 틀(구버전은 원본 백업 후 변환, 신버전 데이터는 편집 차단)
- 같은 문서를 두 탭에서 열면 나중 탭은 읽기 전용 (Web Locks `navigator.locks` — 동시에 열어도 편집 탭은 하나, 탭을 닫으면 저절로 풀림)
- .inkpad 파일(zip: manifest + 문서 + 청크 + PDF 원본) 내보내기/가져오기, 전체 백업/복원(폴더 구조 포함, 새 사본으로 추가)
- 설정 > 저장소: 사용량, 문서·PDF 용량, 저장소 보존 상태, 동기화 대기 건수

**동기화 (기기별 브랜치 + main, 설계: `docs/branch-merge.md`)**
- 오프라인 우선: 모든 읽기/쓰기는 IndexedDB. **자동 동기화는 없다 — 네트워크는 사용자가 누른 동작이 직접 일으킬 때만 쓴다** (`npm run test:e2e -- stores`가 지킨다)
  - 노트: 필기·이름 바꾸기 같은 편집은 기기에만 저장되고, 설정 > 동기화의 **"받기"/"올리기"**를 누를 때 오간다
  - 앱·기타 파일·보드 프리셋: 추가·교체·이름/카테고리 변경 자체가 클라우드 스토어에 올리는 동작이라 **그 항목만 바로** 올린다. 오프라인·실패면 대기로 남고 각 메뉴의 업로드 버튼으로 다시 올린다(노트의 "올리기"는 이 대기를 올리지 않는다). 큰 파일은 올리기 전에 묻는다
- **수동 동기화 편의**(`app/syncReminders.ts`, 설정 > 동기화 편의) — 네트워크를 저절로 쓰지 않는 원칙은 그대로다
  - **편집 화면 노트 칩**: 툴바에 이 노트의 상태(동기화됨·올리기 필요·새 버전·갈라짐·머지 대기·클라우드 없음)를 색 점과 말로(라이브러리 카드는 1비트 꼬리표). 누르면 이 노트만 올리기·받기(이 기기 변경이 있으면 바로 덮지 않고 비교 화면으로)·**변경 버리기**·머지 열기. 버전 기록·동기화 패널은 툴바 오른쪽 메뉴에서. 상태는 이 기기 DB와 마지막으로 본 판정만 읽는다
  - **창 밖의 동기화 기다리기**: 노트 칩·다른 탭에서 시작한 올리기·받기(동기화 잠금)가 진행 중이면 동기화 창은 내용을 가리고 "다른 곳에서 동기화가 진행 중입니다 — 끝날 때까지 기다려 주세요"만 보인다. 그 사이 목록은 반쯤 바뀐 상태라 믿을 수 없고 받기·올리기도 잠금에 막히기 때문. 끝나면 목록을 새로 읽어 보여 준다(편집 화면 옆 패널로 열어 둔 채 칩을 눌러도 같다). 이 창이 시작한 받기·올리기·행 동작은 가리지 않고 평소의 '동기화 중' 표시. 잠금 목록(`navigator.locks.query`)만 보므로 네트워크는 쓰지 않는다. 잠금에 막힌 일괄 받기·올리기는 아무 일 없이 끝나지 않고 "다른 곳에서 동기화가 진행 중입니다"를 알린다
  - **노트를 닫을 때 알림**: 올리지 않은 변경이 있으면 '정리' 버튼이 달린 알림 → 비교 화면에서 올리기(진짜 필기) 또는 변경 버리기(써 보며 공부한 것) — 기기를 바꾸기 전에 잊지 않게 (기본 켬)
  - **할 일 배지**: 라이브러리 동기화 버튼과 앱 아이콘(Badging API, 설치한 앱에서 지원할 때)에 올릴 노트 + 머지 대기 수 (기본 켬)
  - **앱을 열 때 클라우드 확인**(기본 **끔**): 앱을 열거나 돌아올 때 노트·브랜치 목록 메타만 읽어 '받을 것·갈라짐·머지 대기'를 표시한다. 내용은 받지 않고, 30분 안에 다시 열면 확인하지 않는다. 데이터는 노트 100개에 약 35KB, 300개에 약 100KB(gzip 전송 기준 추정, 무작위 실데이터 모양으로 측정)
- **노트 1개 = main 파일 1개 + 기기마다 브랜치 파일 1개**(main `Inkpad/docs/{id}.json`, 브랜치 `Inkpad/branches/{id}@{기기 ID}.json`, gzip). 브랜치는 그 기기만 쓰므로 한 기기의 업로드가 다른 기기의 업로드를 덮는 일이 없다. PDF·이미지 원본은 sha256 내용 주소 파일(`Inkpad/assets/`). 폴더는 기기별 정리 도구라 동기화하지 않고, 노트의 카테고리만 노트 파일에 담겨 동기화된다
- **클라우드 노트 목록**: 설정 > 동기화에 Drive에 저장된 노트 리스트가 뜬다 — 제목 왼쪽, 저장한 기기·시각·받기 버튼은 제목과 같은 높이로 오른쪽 정렬. 기기 이름은 설정에서 직접 정한다. 노트마다 **받기** 버튼으로 골라 내려받는다 — 새·업데이트된 노트는 파란 점, 이 기기에서 지운 노트는 **빨간 점**으로 표시되고(받기는 되살리지 않음), 노트별 받기로 명시적으로 되살린다. 목록 아래 **카테고리 칩**으로 좇혀 보고, 카테고리를 고른 뒤 받을 것 머리글의 **"카테고리 받기"**로 그 카테고리 노트 전체를 한 번에 받는다
- **올리기**: 먼저 **미리보기**(추가/수정/삭제 노트 목록, 원본 수)를 보여주고 확인한 뒤 이 기기의 변경을 **이 기기 브랜치**에 올린다. main이 이 기기가 마지막으로 맞춘 그대로면 main도 이 내용으로 바꾼다(**따라가기, fast-forward**). 이어서 다른 기기의 변경도 받아온다(푸시 → 풀). 노트 메뉴의 "클라우드에 올리기"로 한 노트만 바로 올릴 수도 있다
- **받기 = 클라우드로 완전 동기화**: 미리보기의 **'이 기기에서 바꾼 노트'**(올리지 않은 변경이 있거나 갈라진 노트)마다 **덮기·올리기·건너뛰기(기본 — 이 기기 내용 그대로)**를 고르고, **비교**로 이 기기에서 쓴 것(숨쉬는 빛 테두리로 — 파랑 = 새로 쓴 획, 빨강 = 지운 획, 보라 = 고친 획. 바뀌지 않은 획은 흐리게)을 마지막으로 맞춘 상태 위에 본 뒤 맞춘다(`ui/ChangesView.tsx`, `sync/localChanges.ts` — 비교는 네트워크 없음). 덮으면 이 기기 내용은 **이 기기 스냅샷으로만** 남고 브랜치에 올리지 않는다. 클라우드가 그대로면 기준본으로 되돌리기만 해 내려받지도 않는다(데이터 0)
- **변경 버리기**(노트 칩·비교 화면): 써 보며 공부한 뒤 마지막 동기화 상태로 — **오프라인에서도, 네트워크 0**. 지운 내용은 스냅샷(버전 기록)에 남는다
- **받기 판정**: main이 이 기기 출발점 이후 바뀐 노트만 main으로 따라간다. 출발점은 main을 쓸 때마다 새로 뽑는 신원(mid)으로 비교한다(Drive version은 메타데이터 쓰기에도 오르고 파일을 새로 만들면 다시 시작해 믿을 수 없다). 받기·받기 미리보기·클라우드 목록이 같은 판정(`sync/judge.ts` noteSync, `npm run test:sync`)을 쓰므로 미리보기에 뜬 목록이 곧 받는 목록이다. 기기 데이터가 지워졌어도 받기(또는 목록에서 골라 받기) 한 번이면 복구된다
- **앱·기타 파일은 별도 메뉴에서 관리**: 라이브러리 상단바의 **앱** · **기타 파일** 버튼으로 각각 전용 시트를 연다 — Drive(`Inkpad/apps/`, `Inkpad/files/`)를 스토어로 삼아 상태별(업데이트·올릴 것·설치됨·설치 안 됨·사라짐)로 보여주고, 설치/업데이트/제거/클라우드 삭제를 항목별로 한다. 동기화의 받기·올리기는 노트만 처리한다
- **갈라짐 — 자동 머지 없음**: 이 기기도 고치고 다른 기기도 올린 노트는 **아무것도 덮지 않는다**. 올리기는 이 기기 브랜치에만 올리고, 받기 미리보기에서 덮기·올리기·건너뛰기를 고른다(올리기는 브랜치로 → 머지 관리). 클라우드 목록·라이브러리 카드에 **갈라짐**(빨강)으로 뜬다. 행 메뉴의 **클라우드에 맞추기**는 비교 화면을 거쳐 main으로 덮는다 — 이 기기 내용은 스냅샷으로 남는다. 두 기기가 동시에 main을 따라가 한쪽 쓰기가 덮여도, 진 쪽 내용은 그 기기 브랜치에 있고 main의 '반영된 브랜치' 표식에 없으므로 갈라짐으로 다시 보인다 (`npm run test:branch`)
- **머지 관리**: 동기화 패널 위쪽 카드에 main에 아직 들어가지 않은 기기 브랜치(다른 기기 것 포함)가 뜬다. 행(또는 갈라짐 행의 **머지**)을 누르면 **머지 화면**이 열린다 — 열기 전에 이 기기의 올리지 않은 변경을 먼저 올린다
  - 레이어: **원래 있던 내용(공통) / main에만 / 브랜치에만 / 양쪽에서 내용이 다름**. '원래 있던 내용'을 고르면 그것만 흐림 없이 보인다. 머지에는 삭제가 없어(모두 살리기) 한쪽에라도 있는 획은 기본으로 남는다. 내용이 다른 획은 브랜치의 '고친 목록'으로 가려 **한쪽만 고쳤으면 고친 쪽, 양쪽이 고쳤으면 머지하는 기기 쪽**
  - 레이어마다 보이기/숨기기·강조(나머지는 흐리게)·**모두 버리기**, 고친 획은 기본 규칙/main 쪽/브랜치 쪽, 제목·카테고리·페이지 순서가 다르면 쪽 고르기, 한쪽에만 있는 페이지는 페이지째 버리기, **결과만 보기**, 변경 있는 페이지로 이동, 출처를 숨쉬는 빛 테두리로 표시(바뀌지 않은 획은 흐리게). 패드·컴퓨터 공용(넓으면 오른쪽 패널, 좁으면 아래), 단축키 1–4·H·[ ]·Esc
  - **최종 머지**를 눌러야 main이 바뀐다(세대 + 1, 그 브랜치를 '반영됨'으로). 머지 화면을 연 뒤 다른 기기가 올렸으면 쓰지 않고 새 내용으로 다시 불러온다(작업본은 이어 쓴다). 결과는 이 기기 노트에도 적용하고, 다른 기기는 받기로 따라온다 — 단 이 기기에 아직 머지 안 된 자기 브랜치가 있으면 이 기기 노트는 그대로 둔다
  - **머지 편집기**: 도구(보기·올가미·지우개)는 강조한 레이어(없으면 보이는 레이어 전부)에만 닿는다. 올가미로 고른 획은 끌어 옮기기·버리기·살리기·색 바꾸기·다른 쪽 버전으로 바꾸기, 지우개는 닿은 획을 버린다(원래 있던 획은 버릴 수 없다 — 머지에는 삭제가 없다). 버린 획은 흐리게 + 연한 빨간 테두리로 남고, 결과만 보기에서는 안 보인다. 종이 밖으로 나간 획이 있는 페이지는 그 획까지 넓혀 그린다(종이 밖은 회색 바탕 — 비교 화면도 같다). 되돌리기/다시 하기, 확대(100–300%). 패드는 펜이 도구·손가락이 화면 이동(설정 '손가락으로 그리기'를 켜면 손가락도 도구), 컴퓨터는 마우스가 도구. 단축키 V·L·E·Delete·Enter·⌘Z/⇧⌘Z·+/−
  - **작업본 저장**: 머지 화면에서 한 일은 이 기기에 저장돼(`syncState`, `sync/mergeDraft.ts`) 닫거나 앱이 꺼져도 이어서 한다 — 머지 관리 목록에 '작업 중'으로 표시. 그 사이 다른 기기가 새 판을 올렸으면 항목 키로 새 내용에 다시 얹고 알린다. 최종 머지하면 지운다
  - 미리보기는 편집 엔진이 아닌 가벼운 캔버스(보이는 페이지만, PDF 속지는 원본이 이 기기에 있을 때만). 획은 아래 캔버스, 올가미·선택·끌기는 위 덮개 캔버스에 그린다
- **옛 머지 기록**: 자동 머지를 쓰던 때의 머지 충돌 기록(기기 로컬)은 없앴다 — 머지 결과는 버전 기록의 '머지됨'으로, 덮이기 전 내용은 이 기기 스냅샷으로 본다. 옛 머지 백업 파일(`Inkpad/backups/`)은 버전 기록에서 읽기만 하고 새로 만들지 않는다(보관함 관리에서 정리)
- **열린 노트 보호**: 받기·머지·맞추기·버전 되돌리기가 이 기기의 노트 내용을 바꿀 때, 그 노트를 연 편집 화면은 먼저 메모리의 변경을 기록하고 멈췄다가 바뀐 내용으로 다시 열린다(`storage/docGuard.ts`). 다른 탭에서 편집 중인 노트는 건드리지 않고 건너뛴 뒤 알린다
- **버전 기록**: 편집 화면 툴바의 버전 버튼 — 한 패널에 세 가지를 보여 주고, 행마다 **미리보기**(첫 페이지 + 지금 이 기기 대비 `획 +a / −b`)와 **되돌리기**를 한다
  - **클라우드 버전**: main 노트 파일의 Drive 리비전(머지됨·되돌림 표시, 옛 머지 백업 '별도 보관'도 함께). 고정·해제·삭제. 고정하지 않은 리비전은 약 30일 뒤 Drive가 정리, 고정은 파일당 200개까지. Drive는 고정 해제를 허용하지 않아, 해제는 그 내용을 고정 없는 리비전으로 다시 올리고 고정본을 지운 뒤 원래 최신본을 다시 올려 흉내 낸다 — 클라우드의 '현재'는 바뀌지 않는다
  - **기기 브랜치**: 기기마다 마지막으로 올린 이 노트(머지 전 그 기기의 모습)
  - **이 기기 스냅샷**: 받기·맞추기·변경 버리기·최종 머지·되돌리기로 이 기기 노트가 덮이기 **직전에 자동으로** 남긴 것(`sync/snapshots.ts`, 기기 로컬, 노트당 최근 20개·전체 200MB, 같은 내용이면 건너뜀). 네트워크 없이 되돌릴 수 있다
  - 되돌리면 그 내용이 이 기기의 '올릴 것'이 되고(지금 내용은 스냅샷으로 남는다), 올리면 '되돌림' 버전이 된다. **자동 고정은 하지 않는다** — 옛 리비전을 Drive가 고정해야만 내줄 때만 고정하고 '자동 고정'으로 기록해 보관함 관리에서 풀 수 있다. 되돌림 업로드도 고정하지 않는다
- **보관함 관리**(동기화 패널 아래 버튼, `sync/archive.ts`·`ui/ArchiveSheet.tsx`): 기기별 브랜치 수·용량·머지 안 된 수, **머지 끝난 브랜치 지우기**, 쓰지 않는 기기 **퇴역**(그 기기 브랜치 모두 — 머지 안 된 것이 있으면 경고), **옛 머지 백업 지우기**, 노트가 클라우드에서 지워진 뒤 남은 파일(하루 지난 것) 함께 정리, **스냅샷**(노트당 최근 5개만·모두 지우기), **안 쓰는 노트 조각 정리**(표식 → 45일 뒤에도 안 쓰면 휴지통, 고정한 버전이 쓰는 조각은 남김), **자동 고정 풀기**. 클라우드 파일은 Drive 휴지통으로(30일)
- **문서·폴더 JSON gzip 업로드**: 필기 좌표 배열 기준 실측 2.8배 압축(평문 3.07MB → gzip 1.09MB). appProperties에 제목·기기 이름을 넣어 목록을 메타만으로 그린다
- **바뀐 페이지만 오간다**(`sync/objects.ts`): 노트는 페이지마다 조각(`Inkpad/objects/{해시}.gz`, 내용 주소)으로 올라가고 main·브랜치는 조각 목록(매니페스트)만 담는다. 획 하나를 고치면 그 페이지 조각 하나만 올라가고 받는 기기도 그것만 받는다(10쪽 노트 기준 510KB → 27KB). 받기 목록도 마지막으로 본 뒤 바뀐 파일만 묻는다. 옛 전체 파일 형식도 그대로 읽는다 — 새 형식 노트는 이 버전 이상의 앱에서만 받아지므로 **모든 기기의 앱을 업데이트**해 주세요. 안 쓰는 조각은 보관함 관리에서 정리한다(표식 → 45일 뒤 휴지통)
- **원본 지연 로딩**: "받기"는 노트 정보(JSON)만 내려받는다. PDF·이미지 원본 바이트는 그 원본을 쓰는 문서를 **처음 열 때** 받아오고, 받은 뒤에는 이 기기에 남아 다시 받지 않는다. "원본 모두 받기"로 미리 받을 수도 있다. 5MB보다 큰 파일은 **이어 올리기**(8MB 조각)로 올려, 연결이 끊겨도 받은 곳부터 다시 보낸다
- **삭제는 기기 로컬의 일**: 휴지통 이동·비우기(영구 삭제)는 그 기기에서만 사라진다. 클라우드 사본은 남아 다른 기기에 영향을 주지 않고, 클라우드 목록에서 다시 받으면 되살아난다(로컬 휴지통은 30일 보관) 클라우드 사본 자체를 지우는 것은 클라우드 목록 행의 휴지통 버튼(확인 후 Drive 휴지통으로, 30일 보관)이 담당한다 — 각 기기의 로컬 사본은 그대로 남는다
- 다중 탭 동시 실행 방지(`navigator.locks`), 원격 변경 시 목록 자동 새로고침, 읽기 전용 편집 화면은 바뀐 내용으로 자동 다시 열기

### 작업보드
- 노트·앱·파일을 **무한 격자 캔버스**에 '바로가기'로 놓고 쓴다 (`#/board`)
- **보기 / 편집 두 모드** (상단 가운데 세그먼트)
  - 보기: 카드를 모두 같은 크기로 보여 주고, 탭해서 열기
  - 편집: 격자선·카드 서랍·편집 툴바가 열리고, 카드 이동·그룹 편집이 가능
- **카드**: 노트는 썸네일을 선명하게(없으면 줄무늬/점 패턴), 앱은 이름 기반 그라데이션, 파일은 확장자 색 계열(pdf·시트·슬라이드·이미지). 오른쪽 아래에 종류 배지
- **그룹 박스**: 항목을 담지 않고 묶음만 시각화. 헤더 띠에서 이름·개수, ⋯에서 이름/색/삭제. 배율 50% 이하에서는 안의 항목을 숨기고 이름 타일로 접는다
- **카드 서랍**: 넓은 화면(≥900px)은 오른쪽 패널, 좁으면 아래 서랍. 끌어다 놓거나 ＋로 빈 칸에 놓는다. **카테고리 칩**으로 좇혀 보고, 노트 카테고리 머리글의 **전체 놓기**로 그 카테고리 노트 전체를 한 번에 보드에 놓는다
- **정렬**: 편집 툴바의 정렬에서 이름(가나다)·최근 수정·종류 기준을 고르면 정렬해 가지런한 격자로 배치한다 (지금 순서대로 가지런히도 가능)
- **연결 끊긴 바로가기**: 프리셋에 이름이 함께 저장되어 무엇이 끊겼는지 카드에 보이고, 카드를 누르면(또는 받기 버튼) 클라우드에서 바로 내려받아 다시 연결한다 — 눌렀을 때만 네트워크를 쓴다. '다시 연결' 버튼으로 다른 항목에 이어 붙일 수도 있다
- **미니맵 + 줌 HUD**: 왼쪽 아래. 줌은 10%씩, 배율 수치를 누르면 100%로
- **되돌리기/다시**: 편집 모드에서 ⌘Z / ⇧⌘Z, 두 손가락 탭 / 세 손가락 탭. 지우기는 토스트로 되돌리기
- **프리셋**: 상단 프리셋 칩에서 저장·불러오기, 저장 상태 점 표시
- 연결이 끊긴 바로가기는 '다시 연결' 버튼으로 다른 항목에 이어 붙일 수 있다
- 보드 설정은 기기에 자동 저장(`inkpad.board.v3`)

### 동기화 설정 (Google Drive)
1. Google Cloud Console에서 **Google Drive API** 사용 설정, OAuth 동의 화면(외부) — scope `openid email .../auth/drive.file`
2. **게시 상태를 "프로덕션"으로 변경** (테스트 상태는 refresh token이 7일 뒤 만료됨. 민감 scope가 없어 심사 없이 게시 가능)
3. OAuth 클라이언트(웹 애플리케이션) 생성 — 승인된 리디렉션 URI에 등록:
   - `https://inkpad.<계정 서브도메인>.workers.dev/api/auth/callback` (배포 주소 — `npm run deploy` 끝에 출력된다. 사용자 도메인을 붙였으면 그 주소)
   - `http://localhost:3000/api/auth/callback` (로컬 — `npm run preview`)
4. 값 등록 — 배포본은 아래 명령으로, 로컬은 `.dev.vars`에 (`.dev.vars.example` 참고 — 커밋 금지):

| 이름 | 값 | 배포본에 넣는 곳 |
|---|---|---|
| `GOOGLE_CLIENT_ID` | OAuth 클라이언트 ID | `wrangler.jsonc`의 `vars` (공개 값이라 이미 들어 있음) |
| `GOOGLE_CLIENT_SECRET` | OAuth 클라이언트 보안 비밀 | `npx wrangler secret put GOOGLE_CLIENT_SECRET` |
| `SESSION_SECRET` | `openssl rand -base64 32` | `npx wrangler secret put SESSION_SECRET` |
| `ALLOWED_EMAIL` | 내 Gmail (선택 — 다른 계정 차단) | `npx wrangler secret put ALLOWED_EMAIL` |

> 주의: iOS 홈 화면(PWA)은 Safari와 쿠키 저장소가 분리되어 PWA 안에서 한 번 따로 로그인해야 한다. `SESSION_SECRET`을 바꾸면 모든 기기에서 재로그인이 필요하다.

  - `public/_routes.json`은 Cloudflare Pages 시절 설정으로, Workers에서는 쓰이지 않는다
