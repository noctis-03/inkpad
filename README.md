# Inkpad (가칭)

iPad + Apple Pencil용 개인 필기 웹앱 (PWA). 단계별로 구현 중.

## 현재 단계: Phase 1 로컬 MVP + Phase 2 Google Drive 동기화 (완료)

### 완료된 기능
**필기 엔진 (Phase 0 + 1)**
- 펜/터치 분리, 필압, `getCoalescedEvents`, `getPredictedEvents`(펜 끝 예측), 팜 리젝션
- 두 손가락 팬/핀치 줌(10%~2000%), 한 손가락 스크롤 관성, 두 손가락 탭 = Undo, 세 손가락 탭 = Redo
- 확정 레이어 / 입력 레이어 / 페이지(속지·PDF) 레이어, R-tree로 화면에 보이는 획만 그리기, LOD, 캔버스 픽셀 상한
- 그릴 것이 있을 때만 프레임을 돌린다 — 노트를 열어 두고 가만히 있으면 화면을 다시 그리지 않는다(배터리). 성능 표시(HUD)를 켜면 측정을 위해 계속 돈다
- 키보드 단축키: ⌘Z / ⇧⌘Z, P/H/E/L(도구), Delete(선택 삭제), Esc

**필압 지원 여부에 따른 옵션 (신규)**
| 방식 | 설명 |
|---|---|
| 자동 감지 (기본) | 한 획 안에서 필압이 변하면 "지원", 고정값(0.5/1.0 등)만 오는 획이 연속 2번이면 "미지원"으로 판정해 기기에 저장. 미지원이면 대체 방식으로 자동 전환하고 알림 |
| 필압 | 항상 필압 사용 (Apple Pencil) |
| 속도 | 필압 없는 펜·손가락용. 빠르게 그리면 가늘게 (perfect-freehand simulatePressure) |
| 일정한 굵기 | 굵기 변화 없음 |
- "필압이 없을 때" 대체 방식(속도/일정): 자동 감지 결과가 '없음'일 때, 그리고 손가락·정전식 터치펜·마우스 입력에 적용
- 굵기 변화 폭, 필압 곡선(감마), 최소 필압 조절
- 설정 안의 **필압 테스트 패드**: 그어 보면 pointerType, 필압 범위, 판정 결과를 보여주고 감지 결과를 갱신
- 획마다 외곽선 옵션을 저장하므로 설정을 바꿔도 이미 그린 획 모양은 그대로
- 정전식(고무팁) 터치펜은 브라우저에서 손가락과 구분되지 않으므로 "손가락·터치펜으로 그리기"를 켜서 사용

**시작 화면**: 앱을 처음 열 때 노트 카드 → 줄 → 파란 획(앱 아이콘)이 그려지고 'Inkpad'가 떠오른다(약 1.2초, `index.html` — 앱 코드를 받기 전부터 보인다). 앱이 늦게 준비되면 획이 숨쉬며 기다린다. 다크 모드·동작 줄이기 대응

**노트 여는 방법** (라이브러리 격자에서 카드를 누르면 고른다)
- **편집모드**: 평소대로 쓰고 저장한다
- **뷰어보드**: 읽기 전용
- **낙서모드**: 쓸 수 있지만 **아무것도 저장하지 않는다** — 기록·올리기 대기·편집 잠금·보던 위치·카드 미리보기 모두 건드리지 않고, 나가면 쓴 것은 사라진다. 툴바에 '저장 안 됨', 아래에 안내와 **모두 지우기**(처음 연 상태로). 이름 바꾸기·노트 동기화 칩·버전 기록은 내지 않는다

**선택 모드 · 마킹** — 라이브러리에서 노트·앱·파일 카드를 **꾹 누르면** 선택 모드(누른 카드가 선택된다). 상단 바가 **[완료 · N개 선택됨 · 전체 선택 · ○ ✕ ! · 마킹 지우기]**로 바뀌고, 탭은 열지 않고 선택/해제만 한다. 마킹은 ○·✕·! 중 **하나만** 붙고(다른 걸 누르면 바뀐다, 모두 같은 마킹일 때 한 번 더 누르면 뗀다) 카드 미리보기 한가운데에 크게 보인다(뒤의 미리보기는 살짝 어둡게 블러하고 — 카드를 눌러 여는 창의 베일도 같은 어두운 블러라 겹치지 않는다 — 카드 테두리는 마킹 색 얇은 선). 확인했는지·다시 볼지 표시하는 용도라 **이 기기에만 저장**하고 동기화하지 않는다(노트 파일·수정 시각도 그대로). 영구 삭제한 항목의 마킹은 저절로 정리된다. 완료·Esc·다른 섹션으로 가면 끝난다

**카테고리 묶음** — 카테고리 이름을 `[과제] 디지털 시스템`처럼 `[묶음]`으로 시작하면, 왼쪽 메뉴의 카테고리 목록에서 같은 묶음끼리 **가운데에 묶음 이름이 든 구분선**(── 과제 ──) 아래 모이고 앞의 `[과제]`는 떼고 보인다. 묶음이 이름 순으로 먼저, 마지막 묶음 뒤에 빈 구분선 → 묶음 없는 카테고리 → 미분류. 따로 만들 것 없이 이름만 보고 묶으며, 카테고리 자체(이름·색·동기화)는 그대로다

**도구**
- 편집 도구창(떠 있는 바, 위·아래·옆으로 끌어 옮긴다): **[도구 4] | [색 5 · 굵기 3(가늘게·보통·굵게) · 지금 펜 미리보기] | [되돌리기·다시] ⋯**. 회색 상자 없이 하나의 바를 얇은 선으로 나눈다. 미리보기(또는 선택한 도구를 한 번 더)를 누르면 색 전체·굵기 6단계. 블록 추가·전체 보기·도구 메뉴 접기·상단 중앙으로는 ⋯ 메뉴. 폭이 좁으면 색·굵기를 미리보기 하나로 줄이고 되돌리기도 ⋯로
- 펜↔지우개 전환 버튼: 필기 영역 왼쪽 아래(끌어 옮긴다, 영역 크기가 바뀌면 안으로 다시 맞춘다)
- 펜(색 8 + 직접 선택, 굵기 6단계), 형광펜(반투명, 필기 아래 레이어), 프리셋 5개(탭 = 적용, 길게 누르기 = 현재 펜으로 저장)
- 지우개: 획 단위 (닿은 획을 통째로 지운다 — 획을 잘라 조각을 만들지 않아 기기 간 머지가 단순하다)
- 올가미: 선택 → 끌어서 이동, 삭제, 복제, 색 바꾸기 (문서형에서는 다른 페이지로 옮기면 해당 페이지 소속으로 바뀜)
- Undo/Redo 200단계 (페이지 삭제·복제·순서 변경·속지 변경 포함, 페이지 삭제 되돌리기 시 필기도 함께 복원)
- 빠른 전환 버튼(펜 ↔ 지우개, 끌어서 위치 이동)

**문서형 / 무한 캔버스**
- 문서형: A4 / Letter / A5 / 사용자 지정(mm), 세로·가로, 속지 5종(무지·줄·모눈·점·코넬), 세로 연속 스크롤
- 페이지 추가·삭제·복제·순서 변경(썸네일 길게 눌러 끌기 또는 메뉴), 썸네일 사이드바, 현재 페이지 표시
- 무한 캔버스: 청크(4096) 단위 저장, 점/격자/줄/무지 배경, 전체 보기, 원점 이동

**PDF**
- 가져오기: 새 문서로 / 기존 문서에 페이지 삽입, SHA-256 중복 제거, 암호 PDF(비밀번호 입력, 저장 안 함), 손상 PDF 안내, 페이지별 크기·회전(/Rotate) 반영, 200MB 상한
- 렌더링: pdf.js(legacy 빌드, Web Worker), 줌 단계별 해상도 비트맵 + LRU(총 픽셀 상한), 화면 근처 페이지만 렌더링, 다음 페이지 미리 렌더링
- 내보내기: pdf-lib(Web Worker)로 **원본 PDF 페이지 위에 필기를 벡터로 합침**, 형광펜 투명도, 속지 무늬 벡터, 전체/현재/범위 지정, 암호 PDF는 원본을 이미지로 대체(필기는 벡터 유지)
- 무한 캔버스 → 필기 영역 전체를 PDF 1페이지로

**문서 관리 / 저장**
- 문서 목록(그리드/리스트, 썸네일, 수정일·만든 날·제목 정렬, 제목 검색), 중첩 폴더, 폴더로 이동, 복제, 이름 바꾸기
- 휴지통(30일 뒤 자동 영구 삭제, 복원, 비우기), 휴지통 이동 실행 취소
- 카드 미리보기 일괄 새로고침: 상단바의 새로고침 버튼으로 만들 수 있는 미리보기를 한 번에 다시 만든다 — 원본이 없어 만들 수 없는 PDF 노트는 건너뛴다(원본을 받으면 대상에 들어온다)
- IndexedDB(Dexie): 획이 끝나면 500ms 디바운스로 바뀐 청크만 gzip 압축 저장, 백그라운드 전환·종료 시 즉시 저장, 저장 실패 시 재시도·용량 부족 안내
- 모든 쓰기를 같은 트랜잭션에서 outbox에 기록 (Phase 2 동기화 준비), 같은 엔티티는 합침
- schemaVersion + 마이그레이션 틀(구버전은 원본 백업 후 변환, 신버전 데이터는 편집 차단)
- 같은 문서를 두 탭에서 열면 나중 탭은 읽기 전용 (Web Locks `navigator.locks` — 동시에 열어도 편집 탭은 하나, 탭을 닫으면 저절로 풀림)
- .inkpad 파일(zip: manifest + 문서 + 청크 + PDF 원본) 내보내기/가져오기, 전체 백업/복원(폴더 구조 포함, 새 사본으로 추가)
- 설정 > 저장소: 사용량, 문서·PDF 용량, 저장소 보존 상태, 동기화 대기 건수

**PWA**
- 빌드 시 프리캐시 목록 자동 생성(Service Worker), 첫 설치 후 오프라인 실행, 새 버전 알림
- 홈 화면 추가 안내, `navigator.storage.persist()` 요청

**동기화 (기기별 브랜치 + main, 설계: `docs/branch-merge.md`)**
- 오프라인 우선: 모든 읽기/쓰기는 IndexedDB. **자동 동기화는 없다 — 네트워크는 사용자가 누른 동작이 직접 일으킬 때만 쓴다** (`npm run test:e2e -- stores`가 지킨다)
  - 노트: 필기·이름 바꾸기 같은 편집은 기기에만 저장되고, 설정 > 동기화의 **"받기"/"올리기"**를 누를 때 오간다
  - 앱·기타 파일·보드 프리셋: 추가·교체·이름/카테고리 변경 자체가 클라우드 스토어에 올리는 동작이라 **그 항목만 바로** 올린다. 오프라인·실패면 대기로 남고 각 메뉴의 업로드 버튼으로 다시 올린다(노트의 "올리기"는 이 대기를 올리지 않는다). 큰 파일은 올리기 전에 묻는다
- **수동 동기화 편의**(`app/syncReminders.ts`, 설정 > 동기화 편의) — 네트워크를 저절로 쓰지 않는 원칙은 그대로다
  - **편집 화면 노트 칩**: 툴바에 이 노트의 상태(동기화됨·올리기 필요·새 버전·갈라짐·머지 대기·클라우드 없음)를 카드와 같은 점으로. 누르면 이 노트만 올리기·받기(이 기기 변경이 있으면 바로 덮지 않고 비교 화면으로)·**변경 버리기**·머지 열기. 버전 기록·동기화 패널은 툴바 오른쪽 메뉴에서. 상태는 이 기기 DB와 마지막으로 본 판정만 읽는다
  - **노트를 닫을 때 알림**: 올리지 않은 변경이 있으면 '정리' 버튼이 달린 알림 → 비교 화면에서 올리기(진짜 필기) 또는 변경 버리기(써 보며 공부한 것) — 기기를 바꾸기 전에 잊지 않게 (기본 켬)
  - **할 일 배지**: 라이브러리 동기화 버튼과 앱 아이콘(Badging API, 설치한 앱에서 지원할 때)에 올릴 노트 + 머지 대기 수 (기본 켬)
  - **앱을 열 때 클라우드 확인**(기본 **끔**): 앱을 열거나 돌아올 때 노트·브랜치 목록 메타만 읽어 '받을 것·갈라짐·머지 대기'를 표시한다. 내용은 받지 않고, 30분 안에 다시 열면 확인하지 않는다. 데이터는 노트 100개에 약 35KB, 300개에 약 100KB(gzip 전송 기준 추정, 무작위 실데이터 모양으로 측정)
- **노트 1개 = main 파일 1개 + 기기마다 브랜치 파일 1개**(main `Inkpad/docs/{id}.json`, 브랜치 `Inkpad/branches/{id}@{기기 ID}.json`, gzip). 브랜치는 그 기기만 쓰므로 한 기기의 업로드가 다른 기기의 업로드를 덮는 일이 없다. PDF·이미지 원본은 sha256 내용 주소 파일(`Inkpad/assets/`). 폴더는 기기별 정리 도구라 동기화하지 않고, 노트의 카테고리만 노트 파일에 담겨 동기화된다
- **클라우드 노트 목록**: 설정 > 동기화에 Drive에 저장된 노트 리스트가 뜬다 — 제목 왼쪽, 저장한 기기·시각·받기 버튼은 제목과 같은 높이로 오른쪽 정렬. 기기 이름은 설정에서 직접 정한다. 노트마다 **받기** 버튼으로 골라 내려받는다 — 새·업데이트된 노트는 파란 점, 이 기기에서 지운 노트는 **빨간 점**으로 표시되고(받기는 되살리지 않음), 노트별 받기로 명시적으로 되살린다. 목록 아래 **카테고리 칩**으로 좇혀 보고, 카테고리를 고른 뒤 받을 것 머리글의 **"카테고리 받기"**로 그 카테고리 노트 전체를 한 번에 받는다
- **올리기**: 먼저 **미리보기**(추가/수정/삭제 노트 목록, 원본 수)를 보여주고 확인한 뒤 이 기기의 변경을 **이 기기 브랜치**에 올린다. main이 이 기기가 마지막으로 맞춘 그대로면 main도 이 내용으로 바꾼다(**따라가기, fast-forward**). 이어서 다른 기기의 변경도 받아온다(푸시 → 풀). 노트 메뉴의 "클라우드에 올리기"로 한 노트만 바로 올릴 수도 있다
- **받기 = 클라우드로 완전 동기화**: 미리보기의 **'이 기기에서 바꾼 노트'**(올리지 않은 변경이 있거나 갈라진 노트)마다 **덮기·올리기·건너뛰기(기본 — 이 기기 내용 그대로)**를 고르고, **비교**로 이 기기에서 쓴 것(숨쉬는 빛 테두리로 — 파랑 = 새로 쓴 획, 빨강 = 지운 획, 보라 = 고친 획. 바뀌지 않은 획은 흐리게)을 마지막으로 맞춘 상태 위에 본 뒤 맞춘다(`ui/ChangesView.tsx`, `sync/localChanges.ts` — 비교는 네트워크 없음). 덮으면 이 기기 내용은 **이 기기 스냅샷으로만** 남고 브랜치에 올리지 않는다. 클라우드가 그대로면 기준본으로 되돌리기만 해 내려받지도 않는다(데이터 0)
- **변경 버리기**(노트 칩·비교 화면): 써 보며 공부한 뒤 마지막 동기화 상태로 — **오프라인에서도, 네트워크 0**. 지운 내용은 스냅샷(버전 기록)에 남는다
- **받기 판정**: main이 이 기기 출발점 이후 바뀐 노트만 main으로 따라간다. 출발점은 main을 쓸 때마다 새로 뽑는 신원(mid)으로 비교한다(Drive version은 메타데이터 쓰기에도 오르고 파일을 새로 만들면 다시 시작해 믿을 수 없다). 받기·받기 미리보기·클라우드 목록이 같은 판정(`sync/judge.ts` noteSync, `npm run test:sync`)을 쓰므로 미리보기에 뜬 목록이 곧 받는 목록이다. 기기 데이터가 지워졌어도 받기(또는 목록에서 골라 받기) 한 번이면 복구된다
- **앱·기타 파일은 별도 메뉴에서 관리**: 라이브러리 상단바의 **앱** · **기타 파일** 버튼으로 각각 전용 시트를 연다 — Drive(`Inkpad/apps/`, `Inkpad/files/`)를 스토어로 삼아 상태별(업데이트·올릴 것·설치됨·설치 안 됨·사라짐)로 보여주고, 설치/업데이트/제거/클라우드 삭제를 항목별로 한다. 동기화의 받기·올리기는 노트만 처리한다
- **갈라짐 — 자동 머지 없음**: 이 기기도 고치고 다른 기기도 올린 노트는 **아무것도 덮지 않는다**. 올리기는 이 기기 브랜치에만 올리고, 받기 미리보기에서 덮기·올리기·건너뛰기를 고른다(올리기는 브랜치로 → 머지 관리). 클라우드 목록·라이브러리 카드에 **갈라짐**(빨강)으로 뜬다. 행 메뉴의 **클라우드에 맞추기**는 비교 화면을 거쳐 main으로 덮는다 — 이 기기 내용은 스냅샷으로 남는다. 두 기기가 동시에 main을 따라가 한쪽 쓰기가 덮여도, 진 쪽 내용은 그 기기 브랜치에 있고 main의 '반영된 브랜치' 표식에 없으므로 갈라짐으로 다시 보인다 (`npm run test:branch`)
- **머지 관리**: 동기화 패널 위쪽 카드에 main에 아직 들어가지 않은 기기 브랜치(다른 기기 것 포함)가 뜬다. 행(또는 갈라짐 행의 **머지**)을 누르면 **머지 화면**이 열린다 — 열기 전에 이 기기의 올리지 않은 변경을 먼저 올린다
  - 레이어: **원래 있던 내용(공통) / main에만 / 브랜치에만 / 양쪽에서 내용이 다름**. '원래 있던 내용'을 고르면 그것만 흐림 없이 보인다. 머지에는 삭제가 없어(모두 살리기) 한쪽에라도 있는 획은 기본으로 남는다. 내용이 다른 획은 브랜치의 '고친 목록'으로 가려 **한쪽만 고쳤으면 고친 쪽, 양쪽이 고쳤으면 머지하는 기기 쪽**
  - 레이어마다 보이기/숨기기·강조(나머지는 흐리게)·**모두 버리기**, 고친 획은 기본 규칙/main 쪽/브랜치 쪽, 제목·카테고리·페이지 순서가 다르면 쪽 고르기, 한쪽에만 있는 페이지는 페이지째 버리기, **결과만 보기**, 변경 있는 페이지로 이동, 출처를 숨쉬는 빛 테두리로 표시(바뀌지 않은 획은 흐리게). 패드·컴퓨터 공용(넓으면 오른쪽 패널, 좁으면 아래), 단축키 1–4·H·[ ]·Esc
  - **최종 머지**를 눌러야 main이 바뀐다(세대 + 1, 그 브랜치를 '반영됨'으로). 머지 화면을 연 뒤 다른 기기가 올렸으면 쓰지 않고 새 내용으로 다시 불러온다(작업본은 이어 쓴다). 결과는 이 기기 노트에도 적용하고, 다른 기기는 받기로 따라온다 — 단 이 기기에 아직 머지 안 된 자기 브랜치가 있으면 이 기기 노트는 그대로 둔다
  - **머지 편집기**: 도구(보기·올가미·지우개)는 강조한 레이어(없으면 보이는 레이어 전부)에만 닿는다. 올가미로 고른 획은 끌어 옮기기·버리기·살리기·색 바꾸기·다른 쪽 버전으로 바꾸기, 지우개는 닿은 획을 버린다(원래 있던 획은 버릴 수 없다 — 머지에는 삭제가 없다). 버린 획은 흐리게 + 연한 빨간 테두리로 남고, 결과만 보기에서는 안 보인다. 종이 밖으로 나간 획이 있는 페이지는 그 획까지 넓혀 그린다(종이 밖은 회색 바탕 — 비교 화면도 같다). 되돌리기/다시 하기, 확대(100–300%). 패드는 펜이 도구·손가락이 화면 이동(설정 '손가락으로 그리기'를 켜면 손가락도 도구), 컴퓨터는 마우스가 도구. 단축키 V·L·E·Delete·Enter·⌘Z/⇧⌘Z·+/−
  - **작업본 저장**: 머지 화면에서 한 일은 이 기기에 저장돼(`syncState`, `sync/mergeDraft.ts`) 닫거나 앱이 꺼져도 이어서 한다 — 머지 관리 목록에 '작업 중'으로 표시. 그 사이 다른 기기가 새 판을 올렸으면 항목 키로 새 내용에 다시 얹고 알린다. 최종 머지하면 지운다
  - 미리보기는 편집 엔진이 아닌 가벼운 캔버스(보이는 페이지만, PDF 속지는 원본이 이 기기에 있을 때만). 획은 아래 캔버스, 올가미·선택·끌기는 위 덮개 캔버스에 그린다
- **옛 머지 기록**: 자동 머지를 쓰던 때의 머지 충돌 기록(기기 로컬)은 없앴다 — 머지 결과는 버전 기록의 '머지됨'으로, 덮이기 전 내용은 이 기기 스냅샷으로 본다. 옛 머지 백업 파일(`Inkpad/backups/`)은 버전 기록에서 읽기만 하고 새로 만들지 않는다(보관함 관리에서 정리)
- **열린 노트 보호**: 받기·머지·맞추기·버전 되돌리기가 이 기기의 노트 내용을 바꿀 때, 그 노트를 연 편집 화면은 먼저 메모리의 변경을 기록하고 멈췄다가 바뀐 내용으로 다시 열린다(`storage/docGuard.ts`). 다른 탭에서 편집 중인 노트는 건드리지 않고 건너뛴 뒤 알린다
- **버전 기록**: 편집 화면 툴바의 버전 버튼 — 한 패널에 세 가지를 보여 주고, 행마다 **미리보기**(첫 페이지 + 지금 이 기기 대비 `획 +a / −b`)와 **되돌리기**를 한다
  - **클라우드 버전**: main 노트 파일의 Drive 리비전(머지됨·되돌림 표시, 옛 머지 백업 '별도 보관'도 함께). 고정·해제·삭제. 고정하지 않은 리비전은 약 30일 뒤 Drive가 정리, 고정은 파일당 200개까지. Drive는 고정 해제를 허용하지 않아, 해제는 그 내용을 고정 없는 리비전으로 다시 올리고 고정본을 지운 뒤 원래 최신본을 다시 올려 흉내 낸다 — 클라우드의 '현재'는 바뀌지 않는다
  - **기기 브랜치**: 기기마다 마지막으로 올린 이 노트(머지 전 그 기기의 모습)
  - **이 기기 스냅샷**: 받기·맞추기·변경 버리기·최종 머지·되돌리기로 이 기기 노트가 덮이기 **직전에 자동으로** 남긴 것(`sync/snapshots.ts`, 기기 로컬, 노트당 최근 20개·전체 200MB, 같은 내용이면 건너뜀). 네트워크 없이 되돌릴 수 있다
  - 되돌리면 그 내용이 이 기기의 '올릴 것'이 되고(지금 내용은 스냅샷으로 남는다), 올리면 '되돌림' 버전이 된다. **자동 고정은 하지 않는다** — 옛 리비전을 Drive가 고정해야만 내줄 때만 고정하고 '자동 고정'으로 기록해 보관함 관리에서 풀 수 있다. 되돌림 업로드도 고정하지 않는다
- **보관함 관리**(동기화 패널 아래 버튼, `sync/archive.ts`·`ui/ArchiveSheet.tsx`): 기기별 브랜치 수·용량·머지 안 된 수, **머지 끝난 브랜치 지우기**, 쓰지 않는 기기 **퇴역**(그 기기 브랜치 모두 — 머지 안 된 것이 있으면 경고), **옛 머지 백업 지우기**, 노트가 클라우드에서 지워진 뒤 남은 파일(하루 지난 것) 함께 정리, **스냅샷**(노트당 최근 5개만·모두 지우기), **안 쓰는 노트 조각 정리**(표식 → 45일 뒤에도 안 쓰면 휴지통, 고정한 버전이 쓰는 조각은 남김), **자동 고정 풀기**. 클라우드 파일은 Drive 휴지통으로(30일)
- **문서·폴더 JSON gzip 업로드**: 필기 좌표 배열 기준 실측 2.8배 압축(평문 3.07MB → gzip 1.09MB). appProperties에 제목·기기 이름을 넣어 목록을 메타만으로 그린다
- **바뀐 페이지만 오간다**(`sync/objects.ts`): 노트는 페이지마다 조각(`Inkpad/objects/{해시}.gz`, 내용 주소)으로 올라가고 main·브랜치는 조각 목록(매니페스트)만 담는다. 획 하나를 고치면 그 페이지 조각 하나만 올라가고 받는 기기도 그것만 받는다(10쪽 노트 기준 510KB → 27KB). 받기 목록도 마지막으로 본 뒤 바뀐 파일만 묻는다. 옛 전체 파일 형식도 그대로 읽는다 — 새 형식 노트는 이 버전 이상의 앱에서만 받아지므로 **모든 기기의 앱을 업데이트**해 주세요. 안 쓰는 조각은 보관함 관리에서 정리한다(표식 → 45일 뒤 휴지통)
- **원본 지연 로딩**: "받기"는 노트 정보(JSON)만 내려받는다. PDF·이미지 원본 바이트는 그 원본을 쓰는 문서를 **처음 열 때** 받아오고, 받은 뒤에는 이 기기에 남아 다시 받지 않는다. "원본 모두 받기"로 미리 받을 수도 있다. 5MB보다 큰 파일은 **이어 올리기**(8MB 조각)로 올려, 연결이 끊겨도 받은 곳부터 다시 보낸다
- **삭제는 기기 로컬의 일**: 휴지통 이동·비우기(영구 삭제)는 그 기기에서만 사라진다. 클라우드 사본은 남아 다른 기기에 영향을 주지 않고, 클라우드 목록에서 다시 받으면 되살아난다(로컬 휴지통은 30일 보관) 클라우드 사본 자체를 지우는 것은 클라우드 목록 행의 휴지통 버튼(확인 후 Drive 휴지통으로, 30일 보관)이 담당한다 — 각 기기의 로컬 사본은 그대로 남는다
- 다중 탭 동시 실행 방지(`navigator.locks`), 원격 변경 시 목록 자동 새로고침, 읽기 전용 편집 화면은 바뀐 내용으로 자동 다시 열기

### 작업보드
- 노트·앱·파일을 **무한 격자 캔버스**에 '바로가기'로 놓고 쓴다 (`#/board`)
- **보기 / 편집 두 모드** (상단 가운데 세그먼트)
  - 보기: 카드를 모두 같은 크기로 보여 주고, 탭해서 열기
  - 편집: 격자선·카드 서랍·편집 툴바가 열리고, 카드 이동·그룹 편집이 가능
- **카드**: 노트는 썸네일을 선명하게(없으면 줄무늬/점 패턴), 앱은 이름 기반 그라데이션, 파일은 확장자 색 계열(pdf·시트·슬라이드·이미지). 오른쪽 아래에 종류 배지
- **그룹 박스**: 항목을 담지 않고 묶음만 시각화. 헤더 띠에서 이름·개수, ⋯에서 이름/색/삭제. 배율 50% 이하에서는 안의 항목을 숨기고 이름 타일로 접는다
- **카드 서랍**: 넓은 화면(≥900px)은 오른쪽 패널, 좁으면 아래 서랍. 끌어다 놓거나 ＋로 빈 칸에 놓는다. **카테고리 칩**으로 좇혀 보고, 노트 카테고리 머리글의 **전체 놓기**로 그 카테고리 노트 전체를 한 번에 보드에 놓는다
- **정렬**: 편집 툴바의 정렬에서 이름(가나다)·최근 수정·종류 기준을 고르면 정렬해 가지런한 격자로 배치한다 (지금 순서대로 가지런히도 가능)
- **연결 끊긴 바로가기**: 프리셋에 이름이 함께 저장되어 무엇이 끊겼는지 카드에 보이고, 카드를 누르면(또는 받기 버튼) 클라우드에서 바로 내려받아 다시 연결한다 — 눌렀을 때만 네트워크를 쓴다. '다시 연결' 버튼으로 다른 항목에 이어 붙일 수도 있다
- **미니맵 + 줌 HUD**: 왼쪽 아래. 줌은 10%씩, 배율 수치를 누르면 100%로
- **되돌리기/다시**: 편집 모드에서 ⌘Z / ⇧⌘Z, 두 손가락 탭 / 세 손가락 탭. 지우기는 토스트로 되돌리기
- **프리셋**: 상단 프리셋 칩에서 저장·불러오기, 저장 상태 점 표시
- 연결이 끊긴 바로가기는 '다시 연결' 버튼으로 다른 항목에 이어 붙일 수 있다
- 보드 설정은 기기에 자동 저장(`inkpad.board.v3`)

### 동기화 설정 (Google Drive)
1. Google Cloud Console에서 **Google Drive API** 사용 설정, OAuth 동의 화면(외부) — scope `openid email .../auth/drive.file`
2. **게시 상태를 "프로덕션"으로 변경** (테스트 상태는 refresh token이 7일 뒤 만료됨. 민감 scope가 없어 심사 없이 게시 가능)
3. OAuth 클라이언트(웹 애플리케이션) 생성 — 승인된 리디렉션 URI에 등록:
   - `https://inkpad.<계정 서브도메인>.workers.dev/api/auth/callback` (배포 주소 — `npm run deploy` 끝에 출력된다. 사용자 도메인을 붙였으면 그 주소)
   - `http://localhost:3000/api/auth/callback` (로컬 — `npm run preview`)
4. 값 등록 — 배포본은 아래 명령으로, 로컬은 `.dev.vars`에 (`.dev.vars.example` 참고 — 커밋 금지):

| 이름 | 값 | 배포본에 넣는 곳 |
|---|---|---|
| `GOOGLE_CLIENT_ID` | OAuth 클라이언트 ID | `wrangler.jsonc`의 `vars` (공개 값이라 이미 들어 있음) |
| `GOOGLE_CLIENT_SECRET` | OAuth 클라이언트 보안 비밀 | `npx wrangler secret put GOOGLE_CLIENT_SECRET` |
| `SESSION_SECRET` | `openssl rand -base64 32` | `npx wrangler secret put SESSION_SECRET` |
| `ALLOWED_EMAIL` | 내 Gmail (선택 — 다른 계정 차단) | `npx wrangler secret put ALLOWED_EMAIL` |

> 주의: iOS 홈 화면(PWA)은 Safari와 쿠키 저장소가 분리되어 PWA 안에서 한 번 따로 로그인해야 한다. `SESSION_SECRET`을 바꾸면 모든 기기에서 재로그인이 필요하다.
